An interactive Discrete Mathematics learning and calculation tool for students.

## 🌟 Features

### Discrete Mathematics Tools
- **Logic & Truth Tables** - Generate truth tables for propositional logic operations
- **Set Theory** - Calculate union, intersection, power sets, and Cartesian products
- **Combinatorics** - Compute permutations, combinations, factorials, and binomial expansions
- **Number Theory** - GCD, LCM, Euler's Totient, prime factorization
- **Relations** - Check reflexive, symmetric, transitive properties
- **Graph Visualizer** - Interactive canvas-based graph editor
- **Boolean Algebra** - Boolean expression evaluator and truth table generator

### Digital Logic Tools (4121501)
- **K-Map Solver** - Karnaugh Map minimizer with Quine-McCluskey algorithm
- **Logic Gate Simulator** - Interactive gate builder with real-time evaluation
- **Number Converter** - Convert between Binary, Octal, Decimal, and Hexadecimal

### Simulation Sandbox
- **Multi-Language IDE** - Support for JavaScript, Python (via Pyodide), and Lua
- **Code Examples** - Pre-loaded examples for discrete math algorithms
- **Real-time Execution** - Run code and inspect state

## 🚀 Getting Started

### Prerequisites
- A modern web browser (Chrome, Firefox, Edge, Safari)
- No server required - runs entirely in the browser!

### Installation
1. Clone this repository:
```bash
git clone https://github.com/Tae-devTat/Discrete.git
```

2. Open `index.html` in your web browser

Or use it directly via GitHub Pages at: https://Tae-devTat.github.io/Discrete

## 📖 Usage

### Navigation
- Use the sidebar to navigate between different tools
- Each section includes theory explanations and interactive calculators
- Export results using the 📥 Export button

### Key Features
- **Dark/Light Theme** - Toggle between themes using the moon/sun button
- **Export Results** - Export calculations as printable documents
- **Graph Export** - Save graphs as PNG images
- **Responsive Design** - Works on desktop and tablet devices

## 🛠️ Technologies

- **HTML5** - Structure and layout
- **CSS3** - Modern styling with CSS variables
- **Vanilla JavaScript** - All logic and interactivity
- **Monaco Editor** - Code editor for the sandbox
- **Pyodide** - Python runtime in the browser (sandbox)
